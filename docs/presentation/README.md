## Coordination and assessment

| Assessment | Marks | Evidence to prepare |
|---|---:|---|
| Implementation and demonstration | 20 | Working local flow, recorded fallback, source snippets, input/output examples |
| Project documentation | 25 | Technical report, README, architecture, formulas, references and validation notes |
| Final presentation and coordination | 5 | Rehearsed handoffs, visible module ownership, controlled timing |
| Project outcome | 5 | Actual software behaviour and documented limitations |
| Conclusion and future scope | 5 | Honest contribution and prioritised next steps |
| **Total** | **60** | Evidence must be truthful and reproducible |

The supplied guidelines require a full project report with guide approval, incorporation of Review II corrections, and softcopy submission two days before final review. Their completion is an academic/team responsibility; this pack does not claim approval or submission has happened. If the final review is already sooner than that deadline, contact the guide about the actual submission requirement.
